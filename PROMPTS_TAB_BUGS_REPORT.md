# Отчет о багах во вкладке "Промпты"

## ✅ Исправленные баги

### 🐛 БАГ #1: Ошибка при работе с undefined builtinGuardsOverrides

**Местоположение:** `ui/src/ui/views/telegram.ts`

- Строка 3382 (toggle checkbox для встроенных фильтров)
- Строка 3401 (кнопка удаления встроенных фильтров)

**Проблема:**

```typescript
const overrides = { ...settings.builtinGuardsOverrides };
```

Если `settings.builtinGuardsOverrides` равно `undefined` или `null`, spread оператор вызовет ошибку.

**Исправление:**

```typescript
const overrides = { ...(settings.builtinGuardsOverrides ?? {}) };
```

Использован оператор нулевого слияния (`??`) для безопасного создания копии объекта. Если значение `undefined` или `null`, используется пустой объект `{}`.

**Влияние:**

- **До исправления:** JavaScript ошибка при первом включении/выключении или удалении встроенного фильтра, если настройки еще не инициализированы
- **После исправления:** Корректная работа с фильтрами независимо от состояния настроек

**Воспроизведение бага (до исправления):**

1. Открыть вкладку "Промпты"
2. Перейти в раздел "🛡️ Активные фильтры"
3. Попытаться включить/выключить любой встроенный фильтр
4. Получить ошибку в консоли: `TypeError: Cannot spread non-iterable`

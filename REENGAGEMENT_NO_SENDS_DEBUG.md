# Проблема: Реактивация не отправляет сообщения

## 🔍 Диагностика

### Симптомы

- Логи показывают: `tracked=3 inWindow=0 eligible=0`
- Контакты есть в БД (`tracked=3`)
- Но **ни один не попадает в окно времени** (`inWindow=0`)
- Никто не подходит для отправки (`eligible=0`)

### Что это значит?

**Контакты сохраняются правильно**, но их `last_client_msg_at` (время последнего сообщения) **не попадает в расчетное окно** для отправки реактивации.

## 🛠 Улучшенное логирование (после исправления)

После обновления кода, логи будут показывать:

```
[TG:AgentName] re-engagement contact | chat=123456 name="John"
  last=2026-03-10T15:30:00.000Z silence=11.28d (270.7h)
  alreadySent=[1,2,3] matchingWindows=[12]
```

**Новые поля:**

- `silence=11.28d (270.7h)` - сколько дней/часов молчит контакт
- `matchingWindows=[12]` - в какие окна (дни) попадает этот контакт

## 📊 Как работает окно времени

### Настройки

- `reEngagementDelayFrom=12` - начало диапазона (12 дней)
- `reEngagementDelayTo=14` - конец диапазона (14 дней)

Это создает **3 окна**: день 12, день 13, день 14

### Расчет окна для каждого дня

Для дня N окно рассчитывается так:

```
windowStart = now - N_days - 12_hours
windowEnd   = now - N_days + 12_hours
```

**Пример для дня 12:**

- Сейчас: 2026-03-21 22:23:08
- Окно: `[2026-03-09 10:23:08 ... 2026-03-10 10:23:08]` (24 часа)

### Проблема узких окон

❌ **Проблема:** Окно ±12 часов дает только **24 часа** для каждого дня

✅ **Контакт попадает:** если написал ровно 12 дней назад ±12 часов

❌ **Контакт НЕ попадает:** если написал 11.5 дней назад или 12.5 дней назад

## 🔧 Возможные причины

### 1. Контакты слишком свежие

**Проблема:** Контакты писали меньше 12 дней назад

**Решение:**

- Уменьшить `reEngagementDelayFrom` (например, до 7 или 3 дней)
- Или подождать, пока пройдет достаточно времени

### 2. Контакты уже получили сообщения

**Проблема:** В `alreadySent` уже есть день, на который пытаемся отправить

**Решение:**

- Проверить таблицу `tg_reengagement` в БД
- Очистить старые записи если нужна повторная отправка

### 3. Контакты попадают между окнами

**Проблема:** Контакт молчит 11.8 дней, но окно для дня 12 еще не началось

**Пример:**

- Контакт молчит: 11.8 дней (283 часа)
- Окно день 12: начинается через 4.8 часов
- Результат: `inWindow=0` до следующего cron запуска

**Решение:**

- Подождать следующего cron запуска (каждые 30 минут)
- Контакт попадет в окно когда молчание достигнет 12±0.5 дней

### 4. Временная зона или часовой пояс

**Проблема:** Сервер и клиенты в разных часовых поясах

**Решение:**

- Все даты должны быть в UTC (ISO формат)
- Проверить что `last_client_msg_at` записывается в UTC

## 🎯 Рекомендации

### Немедленные действия

1. **Посмотреть новые логи** после перезапуска агента:

   ```
   matchingWindows=[12]  - контакт попадет в окно дня 12
   matchingWindows=[]    - контакт НЕ попадает ни в какое окно
   ```

2. **Проверить настройки диапазона:**
   - Если контакты молчат 5-7 дней → установить `delayFrom=5, delayTo=7`
   - Если контакты молчат 20+ дней → установить `delayFrom=20, delayTo=30`

3. **Включить "и более":**
   - `reEngagementDelayMore=true`
   - Отправит всем кто молчит **дольше** чем `delayTo`

### SQL для проверки БД

```sql
-- Все контакты агента с временем молчания
SELECT
  chat_id,
  first_name,
  last_name,
  username,
  last_client_msg_at,
  ROUND((julianday('now') - julianday(last_client_msg_at)), 2) as silence_days,
  sent_days
FROM tg_contacts
WHERE agent_id = 'your-agent-id'
ORDER BY last_client_msg_at DESC;

-- Уже отправленные реактивации
SELECT
  chat_id,
  delay_days,
  period_ref,
  sent_at
FROM tg_reengagement
WHERE agent_id = 'your-agent-id'
ORDER BY sent_at DESC;
```

### Тестовый сценарий

1. **Создать тестовый контакт:**
   - Отправить сообщение в бота
   - Подождать 1 день

2. **Настроить реактивацию:**
   - `delayFrom=1, delayTo=1` (отправка на 1 день)
   - Шаблон: "Тест {имя}"

3. **Рестартовать агента** и смотреть логи:
   ```
   re-engagement contact | ... silence=1.05d matchingWindows=[1]
   re-engagement day=1 window=[...] found=1
   re-engagement sent | chat=... day=1
   ```

- [ ] Убедиться что `alreadySent` не содержит дни из диапазона

## 🚀 После исправления

После обновления кода вы сразу увидите:

1. Точное время молчания каждого контакта
2. В какие окна попадает контакт
3. Почему контакт НЕ попадает в окно

Это позволит точно настроить диапазон дней под ваших контактов!
